How the value is scored

Every row records no token in the snapshot — no market cap, no CoinGecko id, no symbol. A protocol that already trades is kept apart in the Live tokens list below, never ranked.

implied = TVL × category multiple × growth × maturity

  • Category multiple — the median market-cap-to-TVL of the protocols in the same category that already trade, computed from this snapshot (a thin category falls back to the overall median, clamped 0.05–2.0).
  • Growth — the 7-day TVL change, clamped to −60%…+120%, weighted at 0.5.
  • Maturity — 0.6 plus up to 0.4 for up to three years listed with no token recorded.

Implied value is this radar's own claim from the snapshot's figures, never a prediction that a token will be issued or when. Data: DefiLlama snapshot, .
